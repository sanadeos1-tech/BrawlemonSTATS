# Brawlemon Stats 🎮

**Специализированное ПО для игроков игры Brawl Stars**

Brawlemon Stats - это приложение, разработанное на **Electron** и **React**, которое помогает игрокам Brawl Stars улучшать свои навыки и стратегии.

## 🌟 Возможности

- **📚 Гайды** - Полезные советы по игре, прокачиванию персонажей и стратегиям
- **💪 Персонажи** - Полный справочник всех бравлеров с характеристиками
- **🗺️ Карты** - Рекомендации персонажей для каждого режима игры
- **🎨 Красивый интерфейс** - Темная тема в стиле Brawl Stars
- **⚡ Быстрое и отзывчивое** - Полностью локальное приложение

## 🚀 Как начать

### Требования
- Node.js (версия 14 и выше)
- npm или yarn

### Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/sanadeos1-tech/BrawlemonSTATS.git
cd BrawlemonSTATS

# 2. Установите зависимости
npm install

# 3. Запустите приложение в режиме разработки
npm start
```

## 🛠️ Технологический стек

- **Electron** - для создания десктопного приложения
- **React** - для UI компонентов
- **CSS3** - стилизация с анимациями и градиентами
- **Node.js** - runtime окружение

```
BrawlemonSTATS/
```

## 📋 Разделы приложения

### Главная (Home)
- Приветствие и описание приложения
- Краткий обзор всех возможностей

### Гайды (Guides)
- Советы по апу персонажей
- Стратегии для разных режимов
- Способы заработка кубков

### Персонажи (Brawlers)
- Полный справочник всех бравлеров
- Информация о редкости
- Характеристики и описание

### Карты (Maps)
- Режимы игры (Gem Grab, Showdown, Bounty, Heist)
- Рекомендуемые персонажи для каждого режима
- Советы и стратегии

## 🎨 Особенности дизайна

- **Темная тема** в стиле Brawl Stars
- **Красные и синие цвета** главного бренда
- **Плавные анимации** и переходы
- **Адаптивный дизайн** для разных размеров экранов
- **Интерактивные элементы** с эффектом hover

## 🤝 Разработка

Для добавления нового функционала:

1. Создайте новый компонент в `src/pages/`
2. Добавьте стили в `src/styles/`
3. Импортируйте компонент в `src/App.js`
4. Добавьте кнопку в боковое меню
